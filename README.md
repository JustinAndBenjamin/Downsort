### WHY DOWNSORT?

I created Downsort because my downloads folder was always a complete mess.
I wanted to fix this once and for all. At first, I manually checked every file extension and dragged them into the right folders. 
But that got old fast.
That’s when Downsort was born. It started as a simple, console-based script, but it did the job.
To level it up, I asked DeepSeek to wrap my existing code into a modern user interface—and here we are!

DeepSeek is still polishing the UI, but once it's finished, we’ll have a fantastic, genuinely useful tool.

You might wonder why I didn't build the GUI myself. The answer is simple: I have ABSOLUTELY NO IDEA OF PYTHON UI LIBRARIES!!!
